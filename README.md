# Four Grids（四象限 + 归档）

一个将 Obsidian 笔记以“四象限 GTD”方式管理的插件：左侧 2×2 四象限，右侧单列归档。支持自定义“看板视图”，也可为 Kanban 插件提供左 2×2 + 右归档的布局与标题着色。

- 插件 ID：`ob-four-grids`
- 最低版本：Obsidian ≥ `1.4.0`

## 主要特性
- 自定义看板视图（`four-grids-board`）
  - 左 2×2 四象限 + 右侧“归档”整列。
  - 标签标题显示为“源文档文件名 + 看板”（例如：`任务清单 看板`）。
  - 针对同一文件，打开看板时复用已存在的标签，不会生成重复标签。
- 四象限标题高亮
  - 重要且紧急（红）、重要不紧急（蓝）、不重要且紧急（橙）、不重要不紧急（灰）。
  - 标题左侧带强调条，提升关注度（可在样式中关闭）。
- 交互体验优化
  - 列头（标题 + 添加行）固定不滚动，只滚动列表区域。
  - “添加/归档/还原”不再插入任何空白行；移动后删除原始行并规范空白。
- 固定章节顺序
  - 自动将源文档章节重排为：重要且紧急 → 重要不紧急 → 不重要且紧急 → 不重要不紧急 → 归档。
- 条目上限（可配置）
  - 归档列默认最多 500 条；每个象限默认最多 50 条；超过自动裁剪旧项，保留最新。
- 自动归档与还原
  - 勾选象限任务 → 移至归档（记录来源象限与日期）。
  - 勾选归档任务 → 还原至原象限。
- 命令与按钮
  - 初始化四象限模板。
  - 快速添加任务到四象限（支持选择象限）。
  - 四个象限各自的快捷添加命令。
  - 功能区按钮：根据设置打开看板或快速添加。
- Kanban 集成（可选）
  - 为启用 `cssclass: kanban-four-quadrants-archive` 的看板笔记提供“左 2×2 + 右归档”的布局与标题着色。

## 安装
1) 复制本项目到你的库（Vault）目录下的 `.obsidian/plugins/`：
```
.obsidian/plugins/ob_four_grids/
  ├─ manifest.json
  ├─ main.js
  ├─ styles.css
  └─ versions.json  (可选)
```
2) 在 Obsidian 设置 → 社区插件 → 启用 `Four Grids`。

## 使用
- 在一个 Markdown 笔记中：
  - 通过命令“初始化四象限清单模板”快速创建 4 象限 + 归档的基本结构；也可以自行创建相同标题：
    - `## 重要且紧急`
    - `## 重要不紧急`
    - `## 不重要且紧急`
    - `## 不重要不紧急`
    - `## 归档`
  - 点击功能区按钮或命令“打开四象限看板”，进入专用看板视图。
  - 在看板标题下的输入框添加任务；或点击条目上的“归档/还原”。
- 同一文件再次点击“看板”按钮时，将直接切换到已打开的该文件看板标签，避免重复创建。

## 设置项
- `使用看板视图模式`（`preferBoardView`）
  - 开启后，功能区按钮默认打开看板视图；关闭则弹出快速添加。
- `自动归档（勾选即移动）`（`autoArchiveOnCheck`）
  - 当文件中任务被勾选时自动移动至“归档”；归档条目被勾选则还原到原象限。
- `归档记录上限`（`maxArchiveItems`，默认 500）
  - 超出时裁剪旧记录，仅保留最新的上限条目。
- `四象限每栏上限`（`maxQuadrantItems`，默认 50）
  - 每个象限超出时裁剪旧记录，仅保留最新的上限条目。

## Kanban 集成（可选）
- 在看板笔记的 Frontmatter 中添加：
```
cssclass: kanban-four-quadrants-archive
```
- 预期 5 列（前四列为四象限，第五列为“归档”），插件样式会将其布局为左 2×2 + 右归档，并对列标题着色。

## 样式与自定义颜色
- 可在 `styles.css` 中或主题片段中覆盖以下 CSS 变量：
```
--fg-IU: #e03131;   /* 重要且紧急 */
--fg-IN: #1971c2;   /* 重要不紧急 */
--fg-NU: #e8590c;   /* 不重要且紧急 */
--fg-NN: #868e96;   /* 不重要不紧急 */
--fg-ARCHIVE: var(--text-muted);
```
- 如需关闭标题左侧强调条，可移除/覆盖相关 `border-left` 样式。

## 常见问题排查
- 打开标签提示“创建此标签的插件不再活动”
  - 说明工作区里存在 `four-grids-board` 视图类型的标签，但插件未注册该视图。
  - 解决：确保插件已启用；关闭相关标签或重置布局；再次启用插件后重新打开看板。
- 看板布局不是 2×2 + 右归档
  - 确认 `styles.css` 已加载、Obsidian 版本 ≥ 1.4.0；检查主题或自定义 CSS 是否覆盖了布局。
- 添加/归档/还原出现空白行
  - 插件现在不会插入分隔空行，并在写回时规范化空白；如果文档中已有历史空白，需要手动清理一次。

## 兼容性
- 需要 Obsidian ≥ 1.4.0。
- 桌面/移动端均可（`isDesktopOnly: false`）。
